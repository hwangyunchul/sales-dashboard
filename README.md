# 황윤철 팀장 영업 관리 대시보드 — 웹 버전

`index.html` **한 파일**로 동작하는 대시보드입니다. GitHub Pages에 올리면 링크로 바로 사용할 수 있습니다.

## 이 웹 버전에서 되는 것
- 업체 추가·수정·삭제, 진행사항/미팅/전화 기록, 오늘 할 일, 월별 이슈 체크
- 자료 업로드(PDF·이미지·엑셀·PPT·한글, 파일당 4MB) 및 온라인 열람·다운로드
- 이슈 다중 선택 시 예상 계약금액 자동 합산, 업체별 진행률 계산

## 데이터는 어디에 저장되나요?
- 입력·업로드한 내용은 **이 페이지를 연 브라우저(IndexedDB)에만 저장**됩니다.
- 서버가 없어서 **다른 기기·다른 브라우저와 자동으로 공유되지 않습니다.**
- 브라우저 방문 기록/사이트 데이터를 지우면 함께 사라집니다.
- 화면 맨 아래 **`JSON으로 백업`** 버튼으로 파일을 내려받아 보관하세요.
- 여러 기기에서 같은 데이터를 쓰려면 AgentBase 대시보드(클라우드 DB)를 사용하세요.

## GitHub Pages로 링크 만들기 (약 5분)
1. github.com → **+** → **New repository** → 이름 `sales-dashboard`, **Public** → Create
2. **uploading an existing file** → `index.html`, `README.md` 업로드 → Commit
3. **Settings** → **Pages** → Branch `main` + `/ (root)` → **Save**
4. 1~2분 뒤 `https://<아이디>.github.io/sales-dashboard/` 접속

## 주의
- Public 저장소는 파일 자체가 공개됩니다. 실제 고객 정보가 담긴 백업 JSON은 저장소에 올리지 마세요.
- 링크를 아는 사람은 누구나 페이지를 열 수 있습니다(입력 내용은 각자 브라우저에 저장됨).
